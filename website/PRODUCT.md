# Nova Website v2

Nova is an MIT-licensed, open-source desktop browser for macOS, Windows and Linux. This independent English/Turkish marketing site helps curious users understand the product, explore its interface, and find official releases.

Product facts: local WebGPU AI (requires a model download and compatible hardware), workspaces, vertical/horizontal tabs, network-level blocking, encrypted sync and native MCP integration. Avoid performance comparisons, invented user counts, testimonials, or privacy guarantees beyond these features.

Repository: https://github.com/unitybtw/nova-browser. Downloads must point to official release assets/pages. Original website and application remain separate.
