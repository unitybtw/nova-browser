## Platform

web

## Users
Power users, developers, and AI enthusiasts looking for a highly productive, beautiful, and AI-native desktop browser.

## Product Purpose
Nova Browser is an open-source, ultra-fast desktop web browser designed from the ground up for modern workflows. It integrates natively with AI assistants via the Model Context Protocol (MCP) and features a glassmorphic aesthetic.

## Positioning
A next-gen browser combining the performance of Chromium with the elegance of Arc and native AI agent integration (MCP) out-of-the-box, enabling true autonomous browsing by AI.

## Operating Context
Used on desktop operating systems (macOS, Windows, Linux) as a primary or secondary browser. Features split-screen workflows, sidebars, and internal `nova://` settings pages.

## Capabilities and Constraints
- Built with Electron, React, Vite, and TailwindCSS.
- Dual-view split screen.
- Native MCP Server running in the main process.
- Privacy-first (no telemetry, built-in adblocker).
- UI is highly glassmorphic.

## Brand Commitments
- Name: Nova Browser
- Aesthetic constraint: Glassmorphic, modern, premium, futuristic.
- Palette hints: Purple, blue, pink gradients (from the generated logo and current website).

## Product Principles
1. **AI-Native First**: Built for LLMs to control as seamlessly as humans.
2. **Uncompromising Aesthetics**: Every pixel must feel premium, glassmorphic, and alive.
3. **Privacy by Default**: No tracking, local storage only, built-in shields.
